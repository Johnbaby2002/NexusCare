About

Handmade EHR information system from a doctor’s perspective.

Project Summary

NexusCare is a lightweight electronic health record system built using HTML5, CSS3, Bootstrap 5, Flask (Python), and MySQL/MariaDB. It supports doctor registration/login and doctor-scoped CRUD operations on patient records, with symptoms-driven workflow and visit status (Upcoming vs Visited).

Tech Stack
  • Frontend: HTML5, CSS3, Bootstrap 5, minimal JavaScript
  • Backend: Python + Flask
  • Database: MySQL / MariaDB
